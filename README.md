## Learning approach

The goal of this repository is not just to collect course files. It is a record of learning TypeScript by:

- studying a concept
- reproducing it in code
- deliberately testing compiler errors
- practicing without AI
- reviewing and explaining concepts in my own words
- using Git to track meaningful changes

## Current focus

TypeScript fundamentals → functions → stronger JavaScript → React + TypeScript.

The repository will continue to evolve as new sections of the course are completed.
